\entry{PokerPeeker - PlanITPoker Vote Audit}{Chrome Extension}{Personal project}{Apr 2026}
\begin{tightitems}
  \item Chrome extension that audits PlanITPoker (planning poker) votes in a browser side panel. It spots vote conflicts in the room data, can mirror a chosen participant's vote, and exports the room's audit data as JSON. Published on the Chrome Web Store.
\end{tightitems}
\entry{VBCS Variable Inspector}{Chrome Extension}{Personal project}{Mar 2026}
\begin{tightitems}
  \item Chrome dev tool for debugging Oracle VBCS/OJET apps. It inspects runtime bindings and namespaces, and comes with a state manager, query, export/import and backup/restore of app state. Published on the Chrome Web Store.
\end{tightitems}
